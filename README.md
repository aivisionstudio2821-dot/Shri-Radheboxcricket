# Radhe Box Cricket — Demo Website

React + Vite + Tailwind CSS demo for Radhe Box Cricket, Ahmedabad.

## Run
1. `npm install`
2. `npm run dev`

## Build
`npm run build`

## Demo Admin
Owner: `owner@radhebox.demo` / `radhe123`
Staff: `staff@radhebox.demo` / `staff123`

## Routes
- `/` public website
- `/book` booking
- `/admin` admin dashboard
